# iFolo Todo (pi-desktop 扩展插件)

适配 **pi-desktop** 智能体工作台的官方 **iFolo Todo** 扩展。

---

## 🌟 核心特性
1. **项目-会话-Todo 实时自动同步**：自动监听本地会话任务流转，将待办执行状态、完成百分比与优先级汇总归类至 iFolo 原生「代办笔记」系统分类；
2. **高保真双模看板**：严格对齐 iFolo 设计令牌（Tokens）与三原色几何 Dot，完美兼容 pi-desktop 亮色与暗色模式；
3. **沉浸式双重视图**：支持在「当前任务流看板」与「iFolo 代办笔记分类库」之间一键平滑切换；
4. **零外部网络安全保证**：纯本地 STDIO JSON-RPC 2.0 与本地 SQLite 嗅探，绝不上报任何私有代码或凭据。
