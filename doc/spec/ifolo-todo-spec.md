# iFolo Todo 侧边栏插件设计规范与交互规格说明 (Spec)

> **版本**：v1.0.0  
> **面向对象**：UI/UX 设计师、前端与原生核心工程师、AI 智能体  
> **设计哲学**：对齐 iFolo 原生设计语言（Liquid Glass 质感、三原色几何构成、极简冷峻与高级触感），适配 pi-desktop 侧边栏工作面板（Work Panel）日夜双模体验。

---

## 一、界面整体布局与视口自适应结构

### 1. 视口约束与尺寸范围
- **宿主承载位置**：pi-desktop 右侧工作区活动栏（`contributes.views`，图标为 `book`，视图 ID 为 `ifolo-todo-sidebar`）；
- **视口宽度区间**：自适应 300px ～ 480px（典型宽度：340px / 380px）；
- **视口高度**：100% 容器高度（Flexbox 纵向贯通布局，内容区溢出滚动）；
- **排版安全边界**：
  ```css
  padding: 12px 14px;
  box-sizing: border-box;
  overflow: hidden;
  ```

### 2. 页面垂直骨架层级 (从上至下)

## 二、视觉系统与日夜模式设计规范 (Tokens & Palette)

严格对齐 iFolo 原生 `tokens.css` 核心色阶，并兼容 pi-desktop 宿主环境注入的 CSS 变量：

### 1. 品牌三原色与状态色定义
- **Logo 几何点**：
  - 蓝色 (Primary)：`#5CA3FF`
  - 绿色 (Secondary / Success)：`#69CF3D`
  - 橙色 (Accent / Todo 专属色)：`#FFA51F`
- **任务状态胶囊映射**：
  - `completed` (已完成)：绿底白字 / 绿字绿描边 (`--success: #41961D` / 暗色 `#A4E08A`)，文字划线删除态；
  - `in_progress` (执行中)：橙色呼吸点 + 橙底 (`--warning: #FFA51F` / 暗色 `#FFCE85`)；
  - `pending` (排队等待)：沉稳中性色 (`--ink-500: #707B89` / 暗色 `#7E8899`)；
  - `cancelled` (已取消)：划线删除中性色 (`--text-muted`)；
  - `priority: high` (高优)：高能红标 (`--danger: #D52026` / 暗色 `#F89194`)。

## 三、核心组件划分与详细交互规则

### 1. 顶部品牌栏 (HeaderBar)
- **元素**：
  - 左侧：三原色点标（`3px` 间距的 `6px` 圆形点）+ 等宽微标 `iFolo Todo`；
  - 右侧：两颗紧凑型操作按钮：
    - `+` (新建/追加)：单击平滑展开/收起速记表单；
    - `↻` (刷新/同步)：单击立即调用 `syncSessionNow` 触发增量拉取；双击强行重载 Webview (`location.reload()`)。
- **状态**：Hover 时边框点亮为 `--accent`，激活态微小下压反馈 (`transform: translateY(1px)`)。

### 2. 项目-会话面包屑导航器 (BreadcrumbNavigator)
- **展示逻辑**：
  - 自动渲染当前会话所属的项目根目录名称与会话主题：
    `📂 [项目名] › 💬 [当前会话标题]`；
  - 文本超长时末尾省略截断 (`text-overflow: ellipsis; white-space: nowrap;`)，鼠标悬停展示原生完整提示。

### 3. 主分段选择器 (SegmentControl)
- **组件结构**：iOS / macOS 原生胶囊滑动分段器；
- **选项卡**：
  1. **当前任务**（徽标显示当前会话任务总数）；
  2. **代办笔记库**（徽标显示 iFolo 中归属于 `todo` 分类的笔记数）。
- **交互**：
  - 点击无缝切换内容面板，切换动画 150ms 缓动；
  - 当切换至「代办笔记库」时，自动滑出搜索过滤栏；切换至「当前任务」时自动收起搜索框。

### 4. 任务进度概览与图表指标 (ProgressMetricCard)
- **指标呈现**：
  - 标题左侧显示状态摘要（如 `会话任务已就绪` / `所有任务已顺利执行完成`）；
  - 右侧呈现百分比与比率（如 `5/6 (83%)`，字体加粗等宽显示）；
  - 中间嵌入高度 `4px` 的自适应微进度条，进度条采用 `--ifolo-green` 填充，带 `transition: width 0.3s cubic-bezier(0.16, 1, 0.3, 1)` 动效。

### 5. 当前会话任务项列表 (TaskItemsList)
- **卡片解构**：
  - 左侧：状态指示勾选框（`16×16px`，圆角 `4px`）：
    - `completed`：实心绿色底，白色对勾 `✓`；
    - `in_progress`：橙色边框 + 呼吸圆点 `●`；
    - `pending`：灰色细边框；
  - 中间：任务标题与说明文本；完成时文字颜色变灰并施加删除线 (`text-decoration: line-through`)；
  - 底部标签：状态徽标 (`task-badge`) + 优先级微标 (`🔥高优` / `🌱低优`)。
- **空状态 (Empty State)**：居中显示柔和提示：“当前会话暂无排队或执行中的任务清单”。

### 6. iFolo 代办分类笔记列表 (NotesCategoryList)
- **卡片解构**：
  - 标题行：左侧笔记名称，右侧徽标（置顶时显示 `📌 置顶`，非置顶显示 `☑️ 代办`）；
  - 摘要行：双行省略预览正文 (`line-clamp: 2`)；
  - 点击事件：单击任意卡片，平滑滑出下方「正文详情模态浮层」。

### 7. 快速沉淀/追加卡片 (QuickCaptureSheet)
- **折叠展开动画**：支持平滑折叠展开；
- **双模式切换**：
  - **新建模式**：输入标题、输入内容，可勾选“设为置顶代办”；
  - **追加模式**：提供目标笔记下拉选择框 `<select>`，自动拉取当前所有代办笔记，用户选中后输入追加条目，点击“汇总入库”原子追加并记录时间戳。

### 8. 笔记详情模态浮层 (DetailSheet)
- **交互**：Bottom Sheet 底部抽屉滑出形态，高度占据视口 85%；
- **私密锁安全保护 (Security State)**：
  - 若调用 `ifolo.readNote` 检测到 `isLocked === true`，详情正文区域自动渲染高质感红色锁屏警示卡：
    > 🔒 **受硬件级私密锁保护**  
    > 此代办笔记已通过 AES-256 硬件密文锁定。请直接在 macOS 的 iFolo 悬浮窗口通过 Touch ID 解锁后查看。

## 四、数据流转、同步与错误处理规范

### 1. 数据监听与双向同步时序
1. **输入源**：
   - 宿主 SQLite：`~/.pi-desktop/pi.sqlite`（`session_todo` 表、`sessions` 表）；
   - iFolo 本地 Markdown：`~/Library/Application Support/iFolo/notes/` 与 `folders.json`。
2. **同步时序**：
   - `SessionTodoWatcher` 监听宿主数据库变动，以 1000ms 周期抓取当前活跃会话的任务状态；
   - 变动发生时，自动排版为带有进度百分比与 Mermaid 图表标记的 Markdown；
   - 调用 iFolo MCP 接口落盘，并自动写入 `folders.json` 归入 `todo` 分类；
   - 前端 Webview 以 1200ms 有界游标轮询 `ifolo.pollChanges`，数据变动时无感局部重绘。

### 2. 界面防御与异常处理
- **API 延迟注入防护**：Webview 初始化时调用 `waitForPiApi(1500)`，避免因 `window.pi` 注入时差产生未定义报错；
- **单文件内联架构**：将 CSS 与核心交互 JS 直接内联至 `views/index.html`，彻底杜绝 Electron/Chromium Webview 对外部资源产生的版本强缓存。
